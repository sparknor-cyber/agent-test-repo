# agent-test-repo# Oppgave for agenten

Lag en fil som heter `kalkulator.py` i denne mappen.
Filen skal inneholde en Python-funksjon `legg_sammen(a, b)` som returnerer summen av to tall.
Skriv også tre enkle tester som viser at funksjonen fungerer riktig, i en fil kalt `test_kalkulator.py`.
Kjør testene og bekreft at de faktisk går gjennom.
